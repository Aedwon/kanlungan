Design system · Direction D

Component states

Every interactive state, side by side. Hover and focus are drawn statically so they can be compared. The default examples also respond to real hover and keyboard focus. Type uses the Snap scale: label 12, small 14, ui 15, body 17, title 20.

Primary button

Clay fill, #F7F2EA text, 2px radius, 15px 500, padding 18px 30px. Hover darkens to color.accent-hover over 200ms. Focus is a 2px #2E211A outline, offset 3px. Disabled has no hover.
