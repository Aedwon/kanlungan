# Kanlungan

Concept repository for a fictional premium interior design and e-commerce brand created as a portfolio project.

Kanlungan is a premium interior design studio with a secondary curated furniture and homeware shop. The design direction is warm modern Filipino. The project must demonstrate both high-end editorial and brand design and credible e-commerce functionality.

Agents: read `AGENTS.md` before any work.

## Status

Concept planning is complete through step 4. The next work is design mockups (steps 5 and 6), which start from `docs/design/design-brief.md`.

## Planning sequence

1. Define Kanlungan's exact service offering. **Complete.**
2. Define the curated shop offering, catalog scope, product taxonomy, and merchandising model. **Complete.**
3. Lock the primary conversion goals. **Complete.**
4. Define the site map, information architecture, page hierarchy, and core user journeys. **Complete.**
5. Build the visual system and design tokens: typography, color, spacing, radii, imagery rules, and motion. **Next.**
6. Design the homepage and reusable core page templates. **Next, run together with step 5.**
7. Decide technical architecture, e-commerce behavior, and implementation details after the product and design direction are stable. **Not started.**

This order is deliberate: business, content, conversion, and information architecture should be settled before visual tokens and page design.

Steps 5 and 6 run together. The visual system is chosen by comparing rendered directions on a real page, then extended to the remaining templates.
